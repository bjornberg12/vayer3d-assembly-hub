# Vayer3d Assembly Hub

Hello! My name is Hugo Martin Liivaleht and i am studying electrical engineering. With work experience in electrical grid infrastructure i have created this website called Vayer3d, where engineers and technicians can view 3d models of electrical grid infrastructure and designers can make super fast concepts. 


Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Run offline on your own computer

The app has no backend — everything (3D scene, circuit simulation) runs in the browser.

1. Install [Bun](https://bun.sh) (or Node.js) once.
2. In the project folder run `bun install` (needs internet once).
3. Run `bun run dev` and open http://localhost:8080 — it now works without internet.
